# 地理求职雷达

这是一个适配手机的渐进式网页应用。岗位数据保存在 `jobs.json`。

本地预览：在本目录启动任意静态网页服务，然后用浏览器访问相应地址。手机与电脑连接同一网络时，可通过电脑的局域网地址访问。

正式上线后，可直接通过网址访问并添加到手机桌面。为了保证每日自动更新，需要将每日检索结果写入 `jobs.json`，或接入云端数据库/API。


## 地理招聘日检与漏项处理（2026-11-04起）

本仓库只维护地理用户。财会用户、财会仓库和个人投递记录不得混入。

### 固定覆盖范围

优先城市：天津、苏州、无锡、常州、杭州、湖州、嘉兴、太原、晋城、长治。
补充城市：南京、南通、镇江、扬州、绍兴、宁波、金华、上海、北京、济南、青岛、合肥、郑州、西安、武汉、长沙、成都。全国其他地区另补充检索，不以这27城为全国总量。

每日逐城交叉检查：教育局/人社/政府正式公告，区县及市直属单位，公办学校官网/官微，高校就业网/双选会岗位表，国家大学生就业服务平台。天津须区分市直属及各区；无锡必须包括江阴、宜兴；宁波必须包括市直属、各区、县及县级市。未取得原始全文或附件的项目列“待核”，不得记成“无招聘”。城市门户可访问不等于全市覆盖。

教师检索不能只含“地理”：同时检索“教师招聘、师资、教育系统、优秀毕业生、人才引进、校园招聘、简历征集”，再从岗位/专业附件中查“地理学、地理科学、人文地理学、社会、社政、社会法治”。综合社会岗位须单独说明历史、思政及教资对应风险。普通应届、部属公费师范生、国优计划、博士岗位必须区分。

继续保留公务员、事业单位和央国企，以及教育出版、地图内容、科普教育、土地/自然资源资产、区域产业研究、工程咨询社会调查、交通选址分析、海洋渔业经济研究、科研助理、国有文旅研学等原有方向；不把研究院/教育集团名称当作事业编或国企证明。

### 逐公告核验及提醒

1. 先读旧 jobs.json、leads.json、collector-status.json，保留未截止旧岗位；未重新搜到不是下架理由。
2. 每份公告读完整正文、所有岗位表/专业表、补充公告；图片表格须视觉核验，动态页面须另行读取。一个公告拆出具体单位/学科/岗位，不能拿总人数、宣讲场次当作地理岗位数。
3. 核对2027届及毕业日期窗口、人文地理硕士/地理科学师范本科、团员、教资及普通话、户籍、学历年龄、是否本硕一致、院校/公费/国优硬门槛。英语四级通过不等于六级通过，不能假设计算机等级证。资格匹配和录用竞争力分开。
4. 专业明显不符、硬性党员、仅其他届、过期、仅博士或用工主体不合范围不晋级。只收简历且正式资格未公布的学校保留线索，写明不等于正式网报；未知条件填未说明。
5. 取最早必须行动节点：预报名、正式报名、缴费、材料补交、现场审核、笔试/试讲。保留具体时刻；同日多区考试提醒冲突。活动或展位截止不能替代求职者报名截止。
6. 当天发现新且可行动机会、7日内截止、必须现场审核、条件/时间变化或采集失效应明确提醒。线上投递、普通宣讲不要求跨城；必须现场笔试/审核不得写成“等面试再去”而遗漏首趟行程。
7. 已核具体岗位进 jobs.json；未闭环只放 leads.json 且 verificationStatus 为“待核验线索”。仍按公告URL合并线索展示，但核验人必须审全同一公告所有岗位，不能因URL已出现漏掉同公告其他职位。
8. 报告分别列新增正式岗位、提前简历征集、近期截止、现场节点、排除原因、未完成覆盖/访问失败。不声称零遗漏、不以少量已核岗位冒充全国总量。

### 采集健康度

collector-sources.json 保存固定城市、宽口径搜索和直接官方栏目。collect_jobs.py 只写 leads.json/collector-status.json，不写 jobs.json；自动抓取不是资格核验。
状态中的 successfulSources 仅表示配置页面解析正常；partial/manual-review/error 都需补查。动态页空白、附件未解析和来源失败不再当成“成功检查且没有岗位”。teacherCoverage 显示配置范围和待人工项，不能解释为城市全量覆盖。

当前程序不会自动理解所有PDF、Excel、DOC嵌图或官微图片；这些必须由核验层阅读。官微、区县学校和临时补充公告可能仍存在覆盖缺口，须在报告里公开，不以健康计数掩盖。
